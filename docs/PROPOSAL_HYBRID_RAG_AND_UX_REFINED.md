# Refined Architecture Proposal: Corpus-Driven Dynamic Word Segmentation, System Prompt Softening & UX Persistence

**Document Status:** REFINED & AUDITED (vwoosh-adversarial-refinement, 4 Lenses)  
**Target Invariants:** Zero Financial Harm, Sub-Millisecond Search Overhead, Zero External API Overhead on Search Path, 100% Client-Side Session Persistence.

---

## 1. Context & Technical Root Causes

### 1.1 The FTS5 Lexical Disconnect
SQLite FTS5 standard tokenizers divide text on whitespace and punctuation.
* The conference talk `[2RBBJ]` title is: *"AGNTCon + MCPCon Europe 2026: Infrastructure **Red Teaming** With Ablitera..."* (tokens: `red`, `teaming`).
* When the attendee typed `redteaming` (single word), FTS5 searched for the token `redteaming`, returning 0 hits.
* The search fallback then searched for other words ("takeaway"), returning general security talks (`[2RB8n]`, `[2RB9K]`).
* The system prompt's rigid negative guardrail (*"state: This topic was not covered..."*) forced the frontier LLM to report that redteaming was absent.

### 1.2 Modal Link Navigation & State Eviction
* Links generated by `marked.js` in `openEssenceModal` lacked `target="_blank"`. Clicking external Sched links caused the browser to navigate in the same tab.
* Browser back-navigation returned to the page, but in-memory chat history in `#chat-messages` was discarded.

## 2. Refined Architectural Specification

### 2.1 Corpus-Driven Dynamic Word Segmentation (`mcp_server.py` & `serve.py`)
* **Zero Hardcoding Invariant:** Rather than maintaining a brittle manual dictionary, extract the canonical conference vocabulary directly from `agntcon2026.sqlite` (2,257 unique domain terms across titles and summaries).
* **Startup Caching:** Cache `CONFERENCE_VOCAB: set[str]` once at module boot ($<5$ms execution).
* **Algorithmic Segmentation:**
  * For any query token $W$ with length $\ge 6$ that is not directly in `CONFERENCE_VOCAB`:
  * Split $W$ into two candidate sub-tokens $W_1$ and $W_2$ where $W_1$ and $W_2$ (or their common morphological stems) exist in `CONFERENCE_VOCAB`.
  * If valid split found (e.g. `redteaming` $\to$ `['red', 'teaming']`, `promptinjection` $\to$ `['prompt', 'injection']`, `agenticworkflow` $\to$ `['agentic', 'workflow']`), expand FTS5 query to:
    $$\left(W \text{ OR } "W_1\ W_2" \text{ OR } (W_1 \text{ AND } W_2)\right)$$
* **Security & ReDoS Protection (SEC Lens):** Max word length checked capped at 32 characters; dynamic programming split bounded to $O(N)$ operations.

### 2.2 System Prompt Softening (Eliminating Brittle Refusals)
* Replace the rigid binary rule #3:
  * *Old:* `3. If the topic was not discussed in the provided excerpts, state: "This topic was not covered in the conference sessions."`
  * *New:* `3. If the attendee asks about a topic or terminology that is not explicitly named in the excerpts, analyze closely related architectural, security, evaluation, or tool concepts that are present (e.g. vulnerability remediation, adversarial guardrails, boundary enforcement), explicitly explaining the connection to the attendee's query. Only state a topic was not covered if no related concepts exist in the excerpts.`
* This empowers the frontier cloud LLM to deliver the same rich conceptual connections that the local model found, while still keeping claims grounded in real session IDs.

### 2.3 Modal Link Enforcement (`app.js`)
* In `openEssenceModal`, immediately after rendering Markdown:
  ```javascript
  modalBody.querySelectorAll("a").forEach(a => {
    if (a.hostname && a.hostname !== window.location.hostname) {
      a.target = "_blank";
      a.rel = "noopener noreferrer";
    }
  });
  ```
* Every external link to Sched, GitHub, or slide PDFs automatically opens in a new tab.

### 2.4 Chat History Persistence in `sessionStorage` (`app.js`)
* Persist chat conversation in `sessionStorage` under key `agntcon_chat_history_v2`.
* Structure: array of `{ role: "user" | "bot", html: string, timestamp: number }`.
* Bounded size: maximum 40 messages retained (circular buffer) to prevent storage overflows.
* On page load or re-opening `#chat-panel`, automatically restore DOM from `sessionStorage`.
* Clicking `🔄 New` cleanly clears `sessionStorage` and resets the chat drawer.
* Zero server tracking — 100% client-side privacy.
