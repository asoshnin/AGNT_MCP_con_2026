# Sponsored Workshop: The Buzz-Word Is Collaboration

**Canonical Presentation on Sched:** [Sponsored Workshop: The Buzz-Word Is Collaboration](https://agntconmcpconeu26.sched.com/event/2RBSY/sponsored-workshop-the-buzz-word-is-collaboration-morgan-martin-tyler-longwell-wes-billman-bradley-axen-block)  
**Speakers:** Bradley Axen (Creator & Maintainer of Goose; Tech Lead, Block), Wes Billman (Engineer, Block), Morgan Martin (Design Lead, Block), Tyler Longwell (Engineer, Block)  
**Relevance Score:** `0.95`

## Essence

This workshop introduces Buzz, Block's open-source, channel-driven workspace designed for seamless collaboration between humans and AI agents. The core insight is to embed agents directly into shared communication and code environments, eliminating the 'human-as-API' bottleneck. Buzz facilitates this by providing a unified platform where agents and people share conversations, repositories, and reviews, enabling direct delegation, steering, and review of agent work. The platform emphasizes portable identity, scoped capabilities, and signed work to ensure secure and auditable collaboration across diverse agent runtimes and models. Attendees gain practical experience in a live project, contributing code and assets alongside a swarm of agents in a shared Git repository.

## Key Takeaways & Recommendations

- Put agents where the work is, integrating them directly into shared communication and code environments rather than using humans as intermediaries.
- Utilize channel-driven workspaces to enable shared conversations, repositories, and reviews between humans and AI agents.
- Implement mechanisms for portable identity, scoped capabilities, and signed work to ensure secure and auditable agent collaboration.
- Design agent ecosystems to support collaboration across different agent runtimes and models within a unified platform.
