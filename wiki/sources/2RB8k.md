# MCP Conformance Testing V1.0, Testing the 2026-07-28 Spec in SDK's and Online

**Canonical Presentation on Sched:** [MCP Conformance Testing V1.0, Testing the 2026-07-28 Spec in SDK's and Online](https://agntconmcpconeu26.sched.com/event/2RB8k/mcp-conformance-testing-v10-testing-the-2026-07-28-spec-in-sdks-and-online-paul-carleton-felix-weinberger-anthropic)  
**Speakers:** Felix Weinberger (Anthropic), Paul Carleton (Member of Technical Staff, Anthropic)  
**Relevance Score:** `0.95`

## Essence

The talk introduces the critical role of MCP Conformance Testing V1.0, a suite of tools designed to ensure interoperability and consistent behavior across various SDK implementations of the Model Context Protocol (MCP). With the 2026-07-28 spec revision, conformance testing has become a mandatory component of the Specification Enhancement Proposal (SEP) process, marking a significant step towards a robust and reliable agent ecosystem. Speakers shared lessons learned from this rollout and unveiled a new hosted conformance testing service. This service allows both client and server developers to validate their deployed MCP implementations against the official specification, thereby fostering a more unified and predictable environment for agent development and deployment.

## Key Takeaways & Recommendations

- Integrate MCP conformance testing into your SDK development lifecycle.
- Utilize the hosted conformance testing service for validating deployed client and server implementations.
- Actively participate in the Specification Enhancement Proposal (SEP) process, understanding that conformance testing is now a prerequisite for new spec revisions.
