# Governed Agent Autonomy: Building a Control Plane for Agentic Systems

**Canonical Presentation on Sched:** [Governed Agent Autonomy: Building a Control Plane for Agentic Systems](https://agntconmcpconeu26.sched.com/event/2RBAR/governed-agent-autonomy-building-a-control-plane-for-agentic-systems-nnenna-ndukwe-qodo-ai)  
**Speakers:** Nnenna Ndukwe (AI Developer Relations Engineering Lead, Qodo AI)  
**Relevance Score:** `0.95`

## Essence

This talk addresses the critical challenge of governing autonomous AI agents, particularly in coding contexts, by proposing a robust control plane architecture. It highlights that while agentic systems offer significant productivity gains, their ability to plan, execute tools, modify files, and consume resources necessitates explicit boundaries to maintain trust and auditability. The core insight is to structure agent autonomy through a multi-layered control plane incorporating plan gates, granular permission controls, human trust review, independent verification mechanisms, and comprehensive runtime observability. This architecture aims to prevent integrity failures and ensure agents operate within defined operational and budgetary constraints, even in complex coding workflows.

## Key Takeaways & Recommendations

- Implement explicit plan gates to review and approve agentic plans before execution.
- Establish granular permission controls to restrict agent access to resources and actions.
- Integrate independent verification mechanisms to validate agent outputs and actions.
- Prioritize comprehensive runtime observability, including telemetry and quota tracing, for auditing and governance.
