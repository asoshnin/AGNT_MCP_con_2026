# Keynote: A New Way To Build Software: How GitHub Is Evolving For a Human, Agent Future

**Canonical Presentation on Sched:** [Keynote: A New Way To Build Software: How GitHub Is Evolving For a Human, Agent Future](https://agntconmcpconeu26.sched.com/event/2RBi2/keynote-a-new-way-to-build-software-how-github-is-evolving-for-a-human-agent-future-marlene-mhangami-senior-developer-advocate-microsoft)  
**Speakers:** Marlene Mhangami (Senior Developer Advocate, Microsoft)  
**Relevance Score:** `0.95`

## Essence

This keynote addresses the transformative impact of AI agents on software development, particularly within the GitHub ecosystem. As AI agents increasingly contribute code, GitHub is evolving to support both developers embracing agent-first workflows and those overwhelmed by agent-generated pull requests and issues. The talk explores how GitHub is adapting its platform to integrate AI agents seamlessly into development pipelines, from automated issue assignment to agent-centric code review processes. It highlights the challenges and opportunities presented by this shift, emphasizing GitHub's role in shaping the future of human-agent collaboration in software engineering.

## Key Takeaways & Recommendations

- Embrace agent-first development pipelines for increased automation.
- Re-evaluate and adapt code review processes to accommodate agent contributions.
- Utilize GitHub's evolving features to manage and integrate AI agent-generated code effectively.
