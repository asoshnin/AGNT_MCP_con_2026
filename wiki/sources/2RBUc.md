**Canonical Presentation on Sched:** [Keynote: State of the Software Factory](https://agntconmcpconeu26.sched.com/event/2RBUc/keynote-state-of-the-software-factory-dexter-horthy-ceo-and-co-founder-humanlayer)

## Essence

Dexter Horthy's keynote, 'State of the Software Factory,' introduces 'context engineering' as a critical discipline for managing complexity in agentic development environments. He posits that as AI agents become integral to software creation, the challenge shifts from merely writing code to effectively orchestrating and providing relevant context to these agents. The talk emphasizes the need for agentic IDEs and collaboration platforms that prevent 'slop' – the degradation of code quality and coherence due to poorly managed agent interactions. Horthy advocates for structured approaches to context provision, ensuring agents operate within well-defined boundaries and access pertinent information without being overwhelmed or misdirected. This paradigm aims to harness agentic capabilities for solving complex codebase problems while maintaining high standards of software integrity and team collaboration.

## Key Takeaways & Recommendations

- Adopt 'context engineering' as a core discipline for managing agent interactions and information flow.
- Invest in agentic IDEs and collaboration platforms designed to prevent 'slop' and maintain code quality.
- Implement structured approaches for providing agents with well-defined and relevant context.
- Focus on orchestrating agent interactions to solve complex codebase problems efficiently.
