# The Modern AI Stack: Agents, MCP and Skills

**Canonical Presentation on Sched:** [The Modern AI Stack: Agents, MCP and Skills](https://agntconmcpconeu26.sched.com/event/2RB8G/the-modern-ai-stack-agents-mcp-and-skills-adewale-abati-independent)  
**Speakers:** Adewale Abati (Staff Developer Advocate, Developer Tooling)  
**Relevance Score:** `0.95`

## Essence

This talk demystifies the modern AI stack, focusing on the interplay between agent harnesses, Multi-Cloud Platforms (MCPs), and skills. It clarifies that agent harnesses provide the execution environment and orchestration logic for AI agents, enabling them to utilize various tools and capabilities. MCPs serve as the underlying infrastructure, offering scalable and secure environments for deploying and managing these agents and their associated skills, abstracting away cloud-specific complexities. Skills are defined as discrete, reusable functionalities or tools that agents can invoke to perform specific tasks, ranging from API calls to complex data manipulations. The core insight is that by understanding these components and their integration, developers can build robust, scalable, and secure AI applications, moving beyond the often-confusing terminology to practical implementation.

## Key Takeaways & Recommendations

- Prioritize clear definition and modularization of 'skills' for reusability and maintainability within agentic systems.
- Leverage Multi-Cloud Platforms (MCPs) to provide a consistent, scalable, and secure deployment environment for AI agents, abstracting underlying infrastructure.
- Focus on building robust 'agent harnesses' that provide secure orchestration and tool-use capabilities for AI agents.
