# Two Users, One App: Designing MCP Apps for Humans and Agents

**Canonical Presentation on Sched:** [Two Users, One App: Designing MCP Apps for Humans and Agents](https://agntconmcpconeu26.sched.com/event/2RB92/two-users-one-app-designing-mcp-apps-for-humans-and-agents-florian-bauer-openai)  
**Speakers:** Florian Bauer (Member of Technical Staff, OpenAI)  
**Relevance Score:** `0.95`

## Essence

This talk addresses the critical challenge of designing 'MCP Apps' where both human users and AI agents interact with the same application state and workflow. The core problem lies in maintaining consistency and coherence when an agent initiates changes, a human user intervenes, and then the agent needs to resume. The proposed solution involves architectural patterns like separating 'draft state' to prevent agents from acting on unapproved human edits, ensuring tool responses and UI elements remain synchronized, and providing clear context when control transitions between human and agent. This enables seamless collaboration by managing shared state, context, and approval flows explicitly.

## Key Takeaways & Recommendations

- Implement a 'separate draft state' mechanism where agent-proposed changes remain distinct until explicitly accepted by the human user.
- Design frontend state to be adaptable and reflect changes originating from both human user interactions and agent instructions.
- Ensure tool responses and user interfaces are consistent, reflecting the current agreed-upon state of the application.
- Provide useful context when control passes between human and agent, clarifying the current state and next expected actions.
