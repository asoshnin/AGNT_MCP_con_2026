# Keynote: Building the Internet of Agents in the Open

**Canonical Presentation on Sched:** [Keynote: Building the Internet of Agents in the Open](https://agntconmcpconeu26.sched.com/event/2RBFQ/keynote-building-the-internet-of-agents-in-the-open-mazin-gilbert-executive-director-of-agentic-ai-foundation)  
**Speakers:** Mazin Gilbert (Executive Director of Agentic AI Foundation)  
**Relevance Score:** `0.68`

## Essence

The keynote framed the 'Internet of Agents' as an open, interoperable ecosystem where autonomous agents discover, negotiate, and collaborate via standardized protocols. Mazin Gilbert emphasized that realizing this vision requires a shared foundation of trust, security, and sandboxed execution to prevent malicious behavior while preserving agent autonomy. He argued that existing AI model APIs must be extended with lightweight, language‑agnostic messaging layers akin to the Model Context Protocol to enable cross‑vendor agent chaining. The talk highlighted the need for observable, eBPF‑based telemetry that can trace agent interactions without compromising performance or privacy. Finally, Gilbert urged the community to adopt open registries for agent metadata and to establish rigorous evaluation suites that measure both functional correctness and emergent safety properties.

## Key Takeaways & Recommendations

- Adopt open, extensible messaging standards (e.g., Model Context Protocol) for agent-to-agent communication.
- Implement mandatory sandboxing and eBPF‑based observability for all deployed agents.
- Establish open agent registries and shared evaluation benchmarks to certify interoperability and safety.
