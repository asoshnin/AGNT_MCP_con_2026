# Beyond Chatbots: Agentic UI With Open Standards

**Canonical Presentation on Sched:** [Beyond Chatbots: Agentic UI With Open Standards](https://agntconmcpconeu26.sched.com/event/2RBAs/beyond-chatbots-agentic-ui-with-open-standards-manfred-steyer-angulararchitects)  
**Speakers:** Manfred Steyer (Trainer and Consultant, ANGULARarchitects)  
**Relevance Score:** `0.95`

## Essence

This talk addresses the critical challenge of integrating agentic AI into user interfaces without succumbing to ad-hoc solutions, tight coupling, and vendor lock-in. It proposes a protocol-driven approach leveraging open standards like AG-UI, A2UI, and MCP Apps to establish clear, message-based boundaries between the UI, agent logic, and underlying tools. The core insight is that by standardizing communication protocols, developers can achieve scalable, maintainable agentic UIs that support dynamic UI generation, robust tool integration, and effective Human-in-the-Loop patterns. This decouples the 'chat' aspect from the underlying agentic intent, autonomy, and tool access, enabling more sophisticated and flexible user experiences.

## Key Takeaways & Recommendations

- Adopt open standards like AG-UI, A2UI, and MCP Apps for agentic UI development to ensure interoperability and reduce vendor lock-in.
- Design agentic systems with clear, message-based boundaries to decouple UI, agent logic, and tools.
- Utilize JSON Schema for defining and processing messages, including text, widgets, and tool calls, to facilitate dynamic UI generation and robust tool integration.
- Focus on the user's intent, agent autonomy, and tool access as core principles, rather than solely on chat-based interactions.
