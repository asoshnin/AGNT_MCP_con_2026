# Agentic AI for Enterprise Mainframes: From Dead Code Elimination To Business Knowledge

**Canonical Presentation on Sched:** [Agentic AI for Enterprise Mainframes: From Dead Code Elimination To Business Knowledge](https://agntconmcpconeu26.sched.com/event/2RB9Q/agentic-ai-for-enterprise-mainframes-from-dead-code-elimination-to-business-knowledge-thamarai-selvi-ravi-kumar-legal-and-general)  
**Speakers:** Thamarai Selvi Ravi Kumar (Senior Mainframe Developer, Legal and General)  
**Relevance Score:** `0.98`

## Essence

This talk presents a real-world case study on leveraging agentic AI, powered by the Model Context Protocol (MCP), to modernize enterprise mainframe systems. The core problem addressed is the pervasive 'dead code' in legacy COBOL applications, which hinders innovation and obscures business logic. The solution involves a multi-agent architecture: a Dead Code Agent identifies unused logic via static analysis, a Code Change Agent safely remediates it with human approval, and a Lineage Agent reverse-engineers business knowledge from COBOL to DB2. MCP acts as a universal adapter, enabling AI agents to interact with mainframe tools and data, significantly reducing analysis time and enhancing the safety and auditability of changes. This approach not only cleans up legacy systems but also transforms complex mainframe logic into accessible business knowledge for non-technical users.

## Key Takeaways & Recommendations

- Start with a problem you already understand deeply within your domain.
- Design prompts and output structures for agents to be reusable and scalable.
- Implement a robust human-in-the-loop approval gate for all AI-generated changes before execution.
- Measure everything: if you can't measure the output, you can't trust it.
