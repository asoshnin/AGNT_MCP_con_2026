# Sponsored Session: Securing the Agentic Universe, One Layer at a Time

**Canonical Presentation on Sched:** [Sponsored Session: Securing the Agentic Universe, One Layer at a Time](https://agntconmcpconeu26.sched.com/event/2Wevo/sponsored-session-securing-the-agentic-universe-one-layer-at-a-time-jake-moghtader-runlayer)  
**Speakers:** Jake Moghtader (Founding ML Engineer, Runlayer)  
**Relevance Score:** `0.95`

## Essence

The proliferation of enterprise agents calling tools and interacting with production systems at scale introduces significant security vulnerabilities, including prompt injection, over-permissioned agents, and behavioral drift, which human review cannot mitigate. The core insight is that a 'defense in depth' strategy is paramount, requiring multiple layers of security controls rather than relying on a single solution. This architecture necessitates applying policies, runtime threat detection, and fine-grained access controls across every layer of the agentic stack. Crucially, this must be coupled with comprehensive full-session observability and behavioral baselining to effectively identify anomalous signals amidst operational noise.

## Key Takeaways & Recommendations

- Implement a 'defense in depth' security architecture for agentic systems.
- Apply policies, runtime threat detection, and fine-grained access controls at every layer of the agentic stack.
- Integrate full-session observability to monitor agent behavior.
- Establish behavioral baselines for agents to detect drift and anomalies.
