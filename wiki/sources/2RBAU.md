# MCP Apps and The Agentic Web

**Canonical Presentation on Sched:** [MCP Apps and The Agentic Web](https://agntconmcpconeu26.sched.com/event/2RBAU/mcp-apps-and-the-agentic-web-liad-yosef-mcp-apps)  
**Speakers:** Liad Yosef (Co-creator, MCP Apps)  
**Relevance Score:** `0.98`

## Essence

MCP Apps address the 'last mile' problem in the emerging agentic web, where autonomous agents primarily interact with services via APIs and MCP, rendering traditional browsers largely obsolete. While agents handle most tasks, certain critical interactions still necessitate human oversight, such as complex decision-making or identity verification. MCP Apps enable services to deliver composable, interactive UI components directly to agents, allowing for human intervention precisely when needed, without requiring a full browser fallback. This architecture supports a 'nearly headless' web, where personal assistants act as the new browsers, orchestrating tasks while seamlessly integrating human-in-the-loop capabilities for trust and critical input.

## Key Takeaways & Recommendations

- Design services to expose functionality via MCP and APIs for agent interaction.
- Integrate MCP Apps for critical human-in-the-loop interactions to maintain trust and brand identity.
- Focus on building infrastructure that supports agent autonomy while providing mechanisms for human verification.
