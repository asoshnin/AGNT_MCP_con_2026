# From Personal Agent To Org Catalog: 13 Specialists, One Orchestrator

**Canonical Presentation on Sched:** [From Personal Agent To Org Catalog: 13 Specialists, One Orchestrator](https://agntconmcpconeu26.sched.com/event/2RB8D/from-personal-agent-to-org-catalog-13-specialists-one-orchestrator-nick-veenhof-gitlab)  
**Speakers:** Nick Veenhof (Director, DevRel Engineering, GitLab)  
**Relevance Score:** `0.95`

## Essence

This talk addresses the common enterprise problem of fragmented, duplicated agent development by proposing a centralized, catalog-driven architecture. The core insight is to move from individual agent experiments to an organizational capability through a 'Chief of Staff' orchestrator delegating tasks to specialized agents, each with defined roles and skill libraries. A critical component is the platform AI catalog, which transforms agent definitions, workflows, and MCP server configurations into reusable organizational assets. This system enables composable skills and scoped memory (user, project, org), fostering reuse and preventing redundant development across teams, all while leveraging open-source tooling and MCP servers for external integrations.

## Key Takeaways & Recommendations

- Establish a centralized AI catalog for agent definitions, flows, and MCP server configurations to promote reuse and prevent duplication.
- Implement a 'Chief of Staff' orchestrator agent to delegate tasks to specialized agents, each with a clear job family, cultural perspective, and skill library.
- Design agents with composable skills and memory scoped to user, project, or organization levels to enhance flexibility and data isolation.
- Utilize open-source tooling and MCP servers for integrating agents with external systems like calendars, email, and internal platforms.
