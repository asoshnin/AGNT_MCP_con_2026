# Keynote: The Browser Isn't Dead Yet

**Canonical Presentation on Sched:** [Keynote: The Browser Isn't Dead Yet](https://agntconmcpconeu26.sched.com/event/2RBq6/keynote-the-browser-isnt-dead-yet-rachel-lee-nabors-founder-mimasocial)  
**Speakers:** Rachel-Lee Nabors (Founder, Mima.social)  
**Relevance Score:** `0.98`

## Essence

The browser, far from dead, is undergoing a profound transformation from a human-centric document reader to an agentic advocate. This shift is driven by AI agents increasingly interacting with websites, with legal rulings establishing that an agent's actions are attributable to the user. The core insight is that the web must evolve to explicitly expose capabilities for machine consumption, moving beyond visual UI. This necessitates a new architecture where sites expose their functionalities via WebMCP, host dedicated MCP servers, and deliver UI as 'MCP Apps,' enabling seamless interaction for both human and AI agents.

## Key Takeaways & Recommendations

- Expose your site's capabilities using WebMCP.
- Host a dedicated MCP server to facilitate agent interactions.
- Ship UI as 'MCP Apps' designed for agentic consumption.
- Integrate frontend, API, and design system teams to build the agentic web.
