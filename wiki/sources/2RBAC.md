# Governance You Can Run: Checkable Properties for Production Agents

**Canonical Presentation on Sched:** [Governance You Can Run: Checkable Properties for Production Agents](https://agntconmcpconeu26.sched.com/event/2RBAC/governance-you-can-run-checkable-properties-for-production-agents-seshu-tolety-siemens)  
**Speakers:** Seshu Tolety (Director - Agentic AI, Siemens)  
**Relevance Score:** `0.92`

## Essence

This talk introduces a novel approach to agent governance, shifting from unenforceable document-based policies to verifiable, checkable properties on live agent systems. It proposes decomposing any agentic system into a concise three-object model, against which specific, testable properties can be defined. The framework prioritizes identifying and mitigating Tier-1 risks that commonly lead to incidents, with regulatory compliance (e.g., EU AI Act, GDPR) emerging as a natural outcome of satisfying these core properties. This vendor-neutral methodology enables immediate application to production agents, ensuring continuous compliance and operational integrity regardless of underlying stack or model provider.

## Key Takeaways & Recommendations

- Decompose agentic systems into a small, manageable three-object model for governance.
- Define governance as individually testable properties against a running agent deployment.
- Prioritize and rank failure modes to focus on Tier-1 risks that cause actual incidents.
- Implement a vendor-neutral framework for agent governance, independent of stack or model provider.
